作品集文档 RAG

一个检索增强系统，用于查询旧版作品集中记录的项目与知识，并根据检索到的段落逐步显示回答。

当前状态
已记录的原型 / 界面已移除
技术
Astro / Node.js / ChromaDB / Ollama

背景

这个项目属于旧版作品集。访客可以询问我的项目，或查询记录在 Markdown 文件中的知识，而不必逐页浏览。

该助手此前曾上线，但已从当前网站移除。本页保留已记录的架构与技术选择，不会重新上线聊天机器人或交互服务。

运行方式与架构

将语料准备与图中展示的在线查询分开，可以更准确地理解系统。

索引

项目与知识相关的 Markdown 文件构成语料。内容经过检索准备后存入 ChromaDB。

ChromaDB 通过 Docker 运行在 Linux VPS 上。该阶段发生在处理问题之前，因此没有出现在图中。

查询

Node.js 后端接收问题，在 ChromaDB 中检索相关段落，并将整理后的上下文交给项目记录版本中由 Ollama 提供的生成模型。

回答随后返回 Astro 界面并逐步显示。本页不会从图中推断具体传输协议或检索参数。

已记录的组件

Astro
作品集界面与回答的逐步显示。
Markdown
描述项目与语料知识的文件。
Node.js
接收问题并协调检索与生成的后端。
ChromaDB
通过 Docker 运行在 Linux VPS 上的文档检索数据库。
Ollama
项目记录版本中使用的生成服务。

当前状态

图中的界面已不再部署于当前作品集。本页不提供在线演示、API 或 VPS 访问。

这里展示的是技术案例：图示解释过去的架构，并不代表当前仍可使用。

限制与范围

本文档无法证明的内容

  • 图示只覆盖查询，不包括语料准备、更新或重新索引。
  • “Top-K”表示按相关性排序后选择若干段落；本页没有记录 K 的具体数值。
  • 本页不提供质量、延迟或覆盖率的量化结果。

新版本需要评估的问题

以下是一般设计问题，并非该原型已经具备的功能：

  • 语料的时效性与可追溯性；
  • 使用代表性问题评估检索效果；
  • 非公开文档的访问权限管理；
  • 来源展示与不确定性的明确处理。
