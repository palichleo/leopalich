01

Moodix：本地 AI 助手

个人项目 · 2026

  • Node.js
  • llama.cpp
  • GGUF
  • ComfyUI
  • Python
  • PyTorch

GitHub 上的源代码 ↗

在自己的电脑上与语言模型对话，让它分析图像并生成图像和视频。 由 llama.cpp 运行的 GGUF 模型（也可选用 ChatGPT、Claude、OpenRouter 等远程模型）负责对话、读取图像，并通过真正的工具调用触发生成；每个视频都需要单独确认。生成始终在本地的内置 Python 引擎上完成：图像、视频、音乐和音效。每次创作时，本地模型都会让出显卡。无依赖的 Node.js 服务器，测试文件超过 130 个。

实测结果 在 RTX 4070 Super 上为 LTX 2.5 重写了视频引擎：成片从 178 秒降到 81 秒，草稿从 46 秒降到 16.5 秒（模型保持加载时为 8.1 秒）。

人体轮廓检测

个人项目 · 2025

  • YOLO11
  • PyTorch
  • OpenCV
  • PyQt5

GitHub 上的源代码 ↗

在游戏《The Finals》中远距离发现肉眼不一定能注意到的人物轮廓。 概念验证：在公开图像数据集上微调 YOLO11n，并在 PyQt5 叠加层中显示检测框。从未在对局中使用，因为那属于作弊。

实测结果 在公开数据集（6,762 张图像）的验证集上 mAP50 为 0.97；仅用我自己的 326 张截图训练时，降至 0.32。

本地多智能体辩论

个人项目 · 2026

  • Node.js
  • Ollama
  • TF-IDF
  • SSE

GitHub 上的源代码 ↗

验证在同一台电脑上，多个在仲裁下辩论的小模型能否得出比单个模型更好的结论。 多个 Ollama 智能体轮流作答，再由仲裁模型综合；上下文由本地词法检索提供。

实测结果 检索环节在 15 个问题上测得召回率 0.86、精确率 0.61。辩论本身的质量尚未评估。

06

加密货币收益率预测

课程项目 · 2024–2026

  • Python
  • Pandas
  • PyTorch
  • LSTM

GitHub 上的源代码 ↗

根据前两小时的分钟级行情，预测加密货币未来两分钟的收益率。 带注意力机制的 LSTM 编码器-解码器，在 84 种加密货币上训练，并在另外 9 种从未见过的币种上测试。最初是个人项目，后来作为课程项目继续。

实测结果 在从未见过的币种上几乎没有效果：一分钟 R² 为 0.07，两分钟为零，平均绝对误差还略差于始终预测为零（0.00193 对比 0.00191）。

07

赛马名次预测

个人项目 · 2026

  • Python
  • Pandas
  • scikit-learn
  • Random Forest

GitHub 上的源代码 ↗

检验模型能否比赔率更准确地预测一匹马是否跑入名次，只使用赛前已知的统计数据。 对 2011 至 2016 年的 19,869 场比赛（Kaggle 上公开的数据集）训练随机森林，剔除赛后才知道的字段，并用最近的比赛做测试。

实测结果 不使用赔率时 ROC AUC 为 0.60，仅用赔率为 0.57。但对模型选中的马每次下注 1 欧元，没有任何选法能被证明可以盈利：模型挑中的多是赔付更低的热门马。
