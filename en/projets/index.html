02

Moodix, a local AI assistant

Personal project · 2026

Chat with a language model, have it analyse images and generate images and videos on your own computer. A GGUF model run by llama.cpp, or optionally a remote model (ChatGPT, Claude, OpenRouter), converses, reads images and triggers generations through real tool calls; every video needs a confirmation. Generation stays local, on a built-in Python engine: images, videos, music and sound effects. The local model frees the graphics card for each creation. Dependency-free Node.js server, more than 130 test files.

Measured result Video engine rewritten for LTX 2.5, on an RTX 4070 Super: a final video went from 178 s to 81 s, a draft from 46 s to 16.5 s (8.1 s when the model stays loaded).

  • Node.js
  • llama.cpp
  • GGUF
  • ComfyUI
  • Python
  • PyTorch

03

Silhouette detection

Personal project · 2025

Spot distant silhouettes in the game The Finals that the eye does not always catch. Proof of concept: YOLO11n fine-tuned on a public image set, boxes drawn in a PyQt5 overlay. Never used in a match, where it would count as cheating.

Measured result mAP50 of 0.97 on validation with the public set (6,762 images). Trained on my own 326 captures alone, the model drops to 0.32.

  • YOLO11
  • PyTorch
  • OpenCV
  • PyQt5

05

Crypto return prediction

Academic project · 2024–2026

Predict a cryptocurrency’s return over the next two minutes from the previous two hours. LSTM encoder-decoder with attention, trained on 84 cryptocurrencies and tested on 9 unseen ones. Started as a personal project, continued as an academic one.

Measured result On unseen cryptocurrencies, almost nothing: an R² of 0.07 at one minute, none at two, and a mean absolute error slightly worse than predicting zero (0.00193 versus 0.00191).

  • Python
  • Pandas
  • PyTorch
  • LSTM

06

Horse racing: will the horse place?

Personal project · 2026

Find out whether a model can predict better than the odds if a horse will place, using statistics known before the start. Random forest on 19,869 races from 2011 to 2016 (a dataset published on Kaggle), with post-race columns removed, tested on the most recent races.

Measured result ROC AUC of 0.60 without the odds, against 0.57 for the odds alone. Yet betting €1 on the selected horses, no selection is demonstrably profitable: the model picks favourites that pay out less.

  • Python
  • Pandas
  • scikit-learn
  • Random Forest

07

Local multi-agent debate

Personal project · 2026

Check whether several small models debating under an arbiter reach better conclusions than a single one, on the same machine. Ollama agents answer in turn, then an arbiter writes the synthesis; a local lexical search supplies the context.

Measured result Retrieval measured on 15 questions: recall 0.86, precision 0.61. The quality of the debate itself has not been evaluated yet.
