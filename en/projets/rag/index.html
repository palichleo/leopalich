Personal project / Document RAG

Document RAG for my portfolio

An assistant that answered questions about my portfolio from my documents, using ChromaDB on a VPS and a model accessed through an external API.

Current state
Documented prototype / interface removed
Technologies
Astro / Node.js / ChromaDB / API LLM

Context

I integrated this assistant into an earlier version of my portfolio so visitors could ask about my projects and Markdown notes without opening every page.

After local trials with Ollama, I kept retrieval on the VPS and moved generation to an external API.

From the trials

The 4B and 8B models I tried did not produce the answers I expected; the 8B was also too slow in this setup.

How it worked

The system had two stages: preparing the documents, then retrieving relevant passages for each question.

Indexing

Markdown files were split into passages, converted into embeddings and indexed in ChromaDB. This preparation happened before queries were processed.

ChromaDB ran in Docker on a Linux VPS.

Query

Node.js received the question and retrieved relevant passages from ChromaDB. It assembled a prompt with that context for the model called through the external API. The Astro interface then displayed the answer progressively.

Limitations

No quantitative measurements of quality, latency or coverage are available for this prototype.

Areas to evaluate

  • corpus freshness and traceability;
  • retrieval evaluation with representative questions;
  • access control for non-public documents;
  • source presentation and explicit handling of uncertainty.
