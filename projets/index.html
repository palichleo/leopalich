Neuf projets en vision par ordinateur, machine learning, IA générative locale, RAG, robotique, sécurité et développement web, avec leurs résultats quand ils ont été mesurés.

01

Moodix, assistant IA local

Projet personnel · 2026

  • Node.js
  • llama.cpp
  • GGUF
  • ComfyUI
  • Python
  • PyTorch

Code source sur GitHub ↗

Discuter avec un modèle de langage, lui faire analyser des images et générer images et vidéos sur son propre ordinateur. Un modèle GGUF exécuté par llama.cpp, ou au choix un modèle distant (ChatGPT, Claude, OpenRouter), converse, lit les images et déclenche les générations par de vrais appels d’outils ; chaque vidéo demande une confirmation. La génération reste locale, sur un moteur Python intégré : images, vidéos, musique et bruitages. Le modèle local libère la carte graphique le temps de chaque création. Serveur Node.js sans dépendance, plus de 130 fichiers de tests.

Résultat mesuré Moteur vidéo réécrit pour LTX 2.5, sur une RTX 4070 Super : une vidéo finale passe de 178 s à 81 s, un brouillon de 46 s à 16,5 s (8,1 s quand le modèle reste chargé).

02

Détection de silhouettes

Projet personnel · 2025

  • YOLO11
  • PyTorch
  • OpenCV
  • PyQt5

Code source sur GitHub ↗

Repérer de loin, dans le jeu The Finals, des silhouettes que l’œil ne voit pas forcément. Preuve de concept : YOLO11n affiné sur un jeu d’images public, boîtes affichées dans une surcouche PyQt5. Jamais utilisé en partie, où ce serait de la triche.

04

Débat multi-agents en local

Projet personnel · 2026

  • Node.js
  • Ollama
  • TF-IDF
  • SSE

Code source sur GitHub ↗

Vérifier si plusieurs petits modèles qui débattent sous un arbitre concluent mieux qu’un seul, sur la même machine. Des agents Ollama répondent à tour de rôle, puis un arbitre synthétise ; une recherche lexicale locale fournit le contexte.

05

Contrôle d'un robot par les gestes

Projet académique · 2025

  • MediaPipe
  • OpenCV
  • MLP
  • Webots

Commander un robot simulé dans Webots. Le sujet portait sur le bras ; notre groupe a choisi la main. À quatre, en cinq jours : MediaPipe extrait les repères de la main et un MLP reconnaît dix gestes, un peu mieux qu’un Random Forest. 06

Prédiction de rendements crypto

Projet académique · 2024–2026

  • Python
  • Pandas
  • PyTorch
  • LSTM

Code source sur GitHub ↗

Prédire le rendement d’une cryptomonnaie sur les deux minutes suivantes à partir des deux heures précédentes. Encodeur-décodeur LSTM avec attention, entraîné sur 84 cryptomonnaies et testé sur 9 autres jamais vues. Commencé en projet personnel, poursuivi en projet académique.

Résultat mesuré Sur les cryptomonnaies jamais vues, presque rien : un R² de 0,07 à une minute, nul à deux minutes, et une erreur absolue moyenne un peu plus élevée qu’en prédisant zéro (0,00193 contre 0,00191).

07

Courses hippiques : cheval placé ou non

Projet personnel · 2026

  • Python
  • Pandas
  • scikit-learn
  • Random Forest

Code source sur GitHub ↗

Voir si un modèle prédit mieux que la cote qu’un cheval finira placé, à partir des statistiques connues avant le départ. Forêt aléatoire sur 19 869 courses de 2011 à 2016 (jeu publié sur Kaggle), sans les colonnes connues après la course, testée sur les courses les plus récentes.

Résultat mesuré ROC AUC de 0,60 sans la cote, contre 0,57 pour la cote seule. Mais en pariant 1 € sur les chevaux retenus, aucune sélection n’est rentable de façon démontrable : le modèle choisit des favoris qui rapportent moins.
