Projet personnel / RAG documentaire

RAG documentaire pour mon portfolio

Un système de recherche augmentée conçu pour interroger les projets et les connaissances documentées de mon ancien portfolio, puis afficher progressivement une réponse fondée sur les passages retrouvés.

État actuel
Prototype documenté / interface retirée
Technologies
Astro / Node.js / ChromaDB / Ollama

Contexte

Ce projet accompagnait une version antérieure de mon portfolio. L’objectif était de permettre à une personne de poser une question sur mes projets ou sur des connaissances consignées dans des fichiers Markdown, sans parcourir chaque page.

L’assistant a été déployé auparavant, mais il a été retiré du site actuel. Cette page conserve l’architecture et les choix documentés ; elle ne remet en ligne ni chatbot ni service interactif.

Fonctionnement et architecture

Le fonctionnement se comprend en séparant la préparation du corpus de la requête visible sur le schéma.

Indexation

Les fichiers Markdown consacrés aux projets et aux connaissances constituaient le corpus. Leur contenu était préparé pour la recherche puis enregistré dans ChromaDB.

ChromaDB fonctionnait dans Docker sur un VPS Linux. Le schéma ne montre pas cette phase, réalisée avant qu’une question puisse être traitée.

Requête

Le backend Node.js recevait la question, recherchait dans ChromaDB les passages jugés pertinents et construisait le contexte transmis au modèle génératif servi par Ollama dans les versions documentées du projet.

La réponse retournait ensuite vers l’interface Astro, où elle s’affichait progressivement. Aucun protocole de transport précis ni aucun paramètre de recherche n’est déduit du schéma.

Composants documentés

Astro
Interface du portfolio et affichage progressif de la réponse.
Markdown
Fichiers décrivant les projets et les connaissances du corpus.
Node.js
Backend chargé de recevoir la question et d’orchestrer la recherche puis la génération.
ChromaDB
Base de recherche documentaire, exécutée avec Docker sur un VPS Linux.
Ollama
Service de génération utilisé dans les versions décrites du projet.

État actuel

L’interface illustrée n’est plus déployée sur ce portfolio. Cette page n’expose ni démo active, ni API, ni accès au VPS.

Le projet est présenté comme une étude de cas technique : le visuel explique une architecture passée, pas une preuve de disponibilité actuelle.

Limites et portée

Ce que cette documentation ne démontre pas

  • Le schéma couvre la requête, mais pas la préparation, la mise à jour ou la réindexation du corpus.
  • Le libellé « Top-K » représente une sélection ordonnée de passages ; aucune valeur de K n’est documentée ici.
  • Aucune mesure quantitative de qualité, de latence ou de couverture n’est présentée sur cette page.

Points à évaluer pour une nouvelle version

Les sujets suivants sont des considérations générales de conception, et non des fonctions revendiquées pour le prototype :

  • fraîcheur et traçabilité du corpus ;
  • évaluation de la recherche avec des questions représentatives ;
  • gestion des droits d’accès pour des documents non publics ;
  • présentation des sources et traitement explicite de l’incertitude.
