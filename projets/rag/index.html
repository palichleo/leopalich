Projet personnel / RAG documentaire

RAG documentaire pour mon portfolio

Un assistant qui répondait aux questions sur mon portfolio à partir de mes documents, avec ChromaDB sur un VPS et un modèle accessible par API externe.

État actuel
Prototype documenté / interface retirée
Technologies
Astro / Node.js / ChromaDB / API LLM

Contexte

J'avais intégré cet assistant à une version précédente de mon portfolio pour permettre aux visiteurs d'interroger mes projets et mes notes en Markdown sans parcourir chaque page.

Après des essais locaux avec Ollama, j'ai gardé la recherche sur le VPS et confié la génération à une API externe.

Pendant les essais

Les modèles 4B et 8B testés ne donnaient pas les réponses attendues ; le 8B était aussi trop lent dans cette configuration.

Fonctionnement et architecture

Le système reposait sur deux étapes : préparer les documents, puis retrouver les passages utiles à chaque question.

Indexation

Les fichiers Markdown étaient découpés en passages, transformés en embeddings puis indexés dans ChromaDB. Cette préparation précédait les requêtes.

ChromaDB fonctionnait dans Docker sur un VPS Linux.

Requête

Node.js recevait la question et recherchait les passages pertinents dans ChromaDB. Il assemblait le prompt avec ce contexte pour le modèle appelé via l'API externe. La réponse s'affichait ensuite progressivement dans l'interface Astro.

Composants

Interface
Astro
Corpus
Markdown
Orchestration
Node.js
Recherche
ChromaDB
Génération
Modèle via API externe
Infrastructure
Docker / VPS Linux pour ChromaDB

Limites

Aucune mesure quantitative de qualité, de latence ou de couverture n'est disponible pour ce prototype.

Pistes d'évaluation

  • fraîcheur et traçabilité du corpus ;
  • évaluation de la recherche avec des questions représentatives ;
  • gestion des droits d'accès pour des documents non publics ;
  • présentation des sources et traitement explicite de l'incertitude.
