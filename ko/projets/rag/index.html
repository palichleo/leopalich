개인 프로젝트 / 문서 RAG

포트폴리오 문서 RAG

제 문서를 바탕으로 포트폴리오에 관한 질문에 답하던 도우미입니다. VPS의 ChromaDB로 내용을 검색하고 외부 API를 통해 모델을 호출했습니다.

현재 상태
문서화된 프로토타입 / 인터페이스 제거됨
기술
Astro / Node.js / ChromaDB / API LLM

배경

방문자가 페이지를 일일이 열지 않고도 제 프로젝트와 Markdown 노트에 대해 질문할 수 있도록 이전 포트폴리오에 이 도우미를 통합했습니다.

Ollama로 로컬 모델을 시험한 뒤 검색은 VPS에 남기고 생성은 외부 API로 옮겼습니다. 시험한 4B와 8B 모델 모두 기대한 답변을 주지 못했고, 8B는 당시 구성에서 속도도 너무 느렸습니다.

작동 방식과 아키텍처

문서를 미리 준비하는 단계와 질문마다 관련 구절을 검색하는 단계로 구성했습니다.

색인

Markdown 파일을 구절 단위로 나누고 embeddings로 변환한 뒤 ChromaDB에 색인했습니다. 질의를 처리하기 전에 진행하는 준비 단계였습니다.

ChromaDB는 Linux VPS에서 Docker로 실행했습니다.

질의

Node.js가 질문을 받아 ChromaDB에서 관련 구절을 검색했습니다. 검색한 문맥을 prompt에 담아 외부 API로 모델을 호출하고, 생성된 답변을 Astro 화면에 점진적으로 표시했습니다.
