포트폴리오 문서 RAG

이전 포트폴리오에 기록된 프로젝트와 지식을 질의하고, 검색된 문단을 바탕으로 한 답변을 점진적으로 표시하도록 만든 검색 증강 시스템입니다.

현재 상태
문서화된 프로토타입 / 인터페이스 제거됨
기술
Astro / Node.js / ChromaDB / Ollama

배경

이 프로젝트는 이전 포트폴리오에 포함되어 있었습니다. 방문자가 각 페이지를 모두 열지 않고도 프로젝트나 Markdown 파일에 기록된 지식을 질문할 수 있게 하는 것이 목적이었습니다.

도우미는 과거에 배포되었지만 현재 사이트에서는 제거되었습니다. 이 페이지는 기록된 구조와 선택을 보존할 뿐 챗봇이나 대화형 서비스를 다시 제공하지 않습니다.

작동 방식과 아키텍처

말뭉치 준비와 그림에 표시된 질의 과정을 나누어 보면 시스템을 더 정확히 이해할 수 있습니다.

색인

프로젝트와 지식을 설명하는 Markdown 파일이 말뭉치를 구성했습니다. 검색할 수 있도록 준비한 내용을 ChromaDB에 저장했습니다.

ChromaDB는 Linux VPS에서 Docker로 실행되었습니다. 질문 처리 전에 완료되는 과정이므로 그림에는 표시되지 않습니다.

질의

Node.js 백엔드가 질문을 받고 ChromaDB에서 관련 문단을 검색한 뒤, 프로젝트에 기록된 버전에서 Ollama가 제공하는 생성 모델에 전달할 문맥을 구성했습니다.

답변은 Astro 인터페이스로 돌아와 점진적으로 표시되었습니다. 그림만으로 특정 전송 프로토콜이나 검색 설정을 추정하지 않습니다.

현재 상태

그림 속 인터페이스는 현재 포트폴리오에 배포되어 있지 않습니다. 이 페이지는 활성 데모, API 또는 VPS 접근을 제공하지 않습니다.

이 프로젝트는 기술 사례로 제시됩니다. 그림은 과거의 구조를 설명하며 현재 사용 가능하다는 증거가 아닙니다.

한계와 범위

이 문서가 입증하지 않는 내용

  • 그림은 질의 과정만 다루며 말뭉치 준비, 갱신 또는 재색인은 보여 주지 않습니다.
  • ‘Top-K' 표기는 관련도 순으로 문단을 선택한다는 뜻이며 K의 구체적인 값은 이 페이지에 기록되어 있지 않습니다.
  • 품질, 지연 시간 또는 범위에 관한 정량 측정값은 이 페이지에 제시하지 않습니다.

새 버전에서 평가할 항목

다음은 일반적인 설계 고려 사항이며 이 프로토타입에 구현되었다고 주장하는 기능이 아닙니다.

  • 말뭉치의 최신성과 추적 가능성;
  • 대표 질문을 활용한 검색 평가;
  • 비공개 문서의 접근 권한 관리;
  • 출처 표시와 불확실성의 명시적 처리.
